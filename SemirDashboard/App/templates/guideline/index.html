🎯 Bạn sẽ học được gì?

Curriculum này chuẩn bị bạn cho phỏng vấn AI Engineer ở các công ty tech VN + regional (Grab, Shopee, VinAI, FPT AI, VNG, Momo). Bạn sẽ có thể:

  • Giải thích từ đầu cách ML model học từ dữ liệu (backprop, gradient descent, loss)
  • Nói về Transformer + Attention ở cấp độ implementation detail (không chỉ concept)
  • Design 1 LLM application đầy đủ: prompt → RAG → tools → eval → deploy
  • Debate về multi-agent architectures (ReAct vs Plan-Execute vs Supervisor)
  • Kể 5+ câu chuyện project theo format STAR với evidence thật

🧪 Final QA Gate cho curriculum này

Bạn có thể trả lời 5 câu này sau khi hoàn thành 40 modules?
  1. Explain the difference between LSTM và Transformer, kể tên 3 lợi thế của attention.
  2. How would you deploy a fine-tuned Llama-2-13B model to serve 1000 QPS with p95 < 500ms?
  3. Design a multi-agent code review system. Vẽ graph, list nodes, define state.
  4. Explain time-series cross-validation. Why can't you use random KFold for stock prediction?
  5. Kể story về 1 lần bạn debug 1 production ML bug từ symptom → root cause → fix → prevention.

Nếu trả lời được 5/5 với confidence + evidence = ready for interview.

📋 Cách sử dụng curriculum

  1. Đọc từ Level 1 → Level 7 tuần tự. Đừng skip.
  2. Mỗi module có QA gate ở cuối — tự test trước khi qua module kế.
  3. Xem Evidence box — link tới code thật, đọc + run + hiểu.
  4. Đọc References — 1 paper + 1 blog per module.
  5. Sau mỗi Level, tự viết 1 lab notebook implement 1 concept.
  6. Cuối curriculum: mock interview với friend/mentor. Time your answers.
