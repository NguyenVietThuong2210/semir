🎓 Core ML

Supervised Learning
Learning từ labeled data (x, y). Ex: dự đoán giá cổ phiếu, spam classifier. L1.1
Unsupervised Learning
Học pattern từ data không label. Ex: clustering khách hàng, anomaly detection.
Reinforcement Learning
Học từ reward signal, không có label sẵn. Ex: RLHF trong LLM alignment. L4.4
Bias-Variance Tradeoff
Balance giữa model simple (high bias) và complex (high variance). Diagnostic overfitting/underfitting. L2.1
Overfitting
Model memorize training data, không generalize. Symptom: train acc cao, val acc thấp, gap lớn.
Underfitting
Model quá đơn giản, không capture pattern. Train và val đều thấp.
Regularization
Kỹ thuật chống overfit: L1, L2, dropout, early stopping, weight decay. L2.2
Cross-Validation (CV)
Đánh giá honest model bằng cách split data multiple folds. K-Fold, Stratified, TimeSeriesSplit. L1.5
Time-Series Split
CV cho time-series với gap để tránh label leak. L2.4
Walk-forward Validation
Train quá khứ, validate tương lai gần. Expanding hoặc rolling window.
Look-ahead Bias
Feature dùng info tương lai — model "biết trước" → deploy fail.
Feature Engineering
Encode domain knowledge thành số cho model. RSI, MACD, MA. L1.2
Decision Tree
Binary split-based classifier. Foundation của tree-based ensemble. L1.3
Random Forest
Bagging + random feature subset. Ensemble giảm variance của trees.
Gradient Boosting
Sequential ensemble — cây N sửa sai cây trước. XGBoost, LightGBM, CatBoost.
XGBoost
Extreme Gradient Boosting. 5 innovations: 2nd-order Taylor, L1+L2, sparsity-aware, weighted quantile sketch, parallelization.
LightGBM
Leaf-wise growth, 3-10× faster XGBoost, native categorical support.
CatBoost
Symmetric trees, best cho categorical features nhiều.
Optuna
Bayesian hyperparameter search framework. TPE sampler default. L1.5
Calibration
Ensure probability output match actual frequency. Platt, Isotonic methods. L1.6
ECE (Expected Calibration Error)
Metric đo calibration. Target < 0.02 cho production.
SHAP (SHapley Additive exPlanations)
Feature importance với math guarantees. TreeExplainer fast cho tree. L2.5
Permutation Importance
Model-agnostic. Shuffle 1 feature, measure accuracy drop.
SMOTE
Synthetic Minority Oversampling. Interpolate minority samples cho imbalanced.
Class Weight
Inverse-freq weight cho imbalanced. Loss cân bằng.

🧠 Deep Learning

Perceptron
Foundation NN unit. w·x + b, activation. Rosenblatt 1957.
MLP (Multi-Layer Perceptron)
Stacked perceptron với non-linear activation. Universal approximator. L3.1
Backpropagation
Compute gradient via chain rule. Foundation of gradient descent trong NN.
Gradient Descent
Iterative optimizer: w -= lr · ∂L/∂w.
SGD (Stochastic Gradient Descent)
Mini-batch gradient descent. Standard cho DL.
Momentum
Accumulate gradient direction. Smoother path, escape local minima. β=0.9 default.
Adam
Momentum + RMSprop. Adaptive LR per param. Default cho most DL. L3.2
AdamW
Decoupled weight decay. Better generalization. Modern Transformer default.
Lion
Google 2023 optimizer. sign(momentum) only. Memory efficient, matches AdamW.
Learning Rate Schedule
Time-varying LR. Cosine, warmup+cosine, step decay.
Vanishing Gradient
Sigmoid derivative < 0.25 → deep NN gradient → 0. Fix: ReLU, BN, residual.
Exploding Gradient
Gradient magnitude blow up. Fix: gradient clipping norm 1.0.
ReLU
Rectified Linear Unit. max(0, x). Default activation modern DL.
GELU
Gaussian Error Linear Unit. x · Φ(x). Transformer default.
Softmax
Normalize logits → probability. Multi-class output.
Dropout
Random turn off neurons during train. Regularizer, ensemble effect.
Batch Normalization
Normalize activations per batch. Faster train, higher LR. Not for RNN.
Layer Normalization
Normalize per-sample. Transformer default.
RMSNorm
Skip mean subtract in LayerNorm. 10-15% faster. LLaMA uses.
Residual Connection
y = x + F(x). Skip connection. Enable deep networks. ResNet, Transformer.
CNN
Convolutional NN. Spatial pattern via kernel + weight sharing. L3.4
ResNet
Residual Network (He 2015). 152 layers feasible. Standard image classifier.
RNN
Recurrent NN. Hidden state carry through time. Vanishing gradient.
LSTM
Long Short-Term Memory. 3 gates + cell state. Fix RNN vanishing. L3.5
GRU
Simplified LSTM. 2 gates, no cell state. Faster train.
Attention
Weighted sum của values, weights = softmax(query·keys). Foundation Transformer. L4.2
Self-attention
Q, K, V all from same input. Model relationship between all positions.
Multi-Head Attention
Multiple attention heads parallel. Mỗi học aspect khác.
Transformer
Vaswani 2017. Self-attention + FFN + LN + residual. Foundation LLM.
Cross-Attention
Q từ decoder, K/V từ encoder. Encoder-decoder Transformer.
Causal Mask
Prevent attention lookahead. GPT decoder-only necessary.
Positional Encoding
Inject sequence order info. Sinusoidal, learned, RoPE.
RoPE (Rotary Position Embedding)
Rotate Q, K by position. Relative-aware. LLaMA uses.
FlashAttention
Kernel fusion optim. 2-4× speedup attention. Dao 2022.
Mixup
Data augmentation: blend 2 samples + labels. Smoother decision boundary.
Label Smoothing
Soft one-hot: replace 1 → 0.9. Prevent overconfidence.
Stochastic Depth
Drop entire residual block randomly. Regularizer cho deep nets.

📚 LLM Basics

LLM (Large Language Model)
Transformer-based, 1B+ params, text generation. GPT, Claude, LLaMA, Gemini.
Foundation Model
Large pretrained model adaptable multiple downstream tasks.
Tokenization
Text → tokens (integers). BPE, WordPiece, SentencePiece. L4.1
BPE (Byte-Pair Encoding)
Merge frequent character pairs iteratively. Standard cho GPT.
WordPiece
BERT tokenizer. Merge for likelihood maximization.
SentencePiece
Language-agnostic tokenizer. LLaMA, T5 uses. Best for CJK/VN.
Embedding
Token → dense vector. Learnable lookup table.
Tied Weights
Output projection = embedding.T. Save 50M+ params.
Context Window
Max tokens LLM process at once. GPT-4o 128k, Claude 3 200k, Gemini 1M.
Encoder-only
BERT family. Bidirectional attention. Classification, extraction.
Decoder-only
GPT family. Causal attention. Generation, chat, code.
Encoder-Decoder
T5, BART, mBART, mT5. Translation, summarization.

🎯 LLM Training

Pretraining
Massive unsupervised on text corpus. CLM, MLM, denoising objectives. L4.3
CLM (Causal Language Modeling)
Next-token prediction. GPT objective.
MLM (Masked Language Modeling)
Predict masked tokens. BERT objective.
Chinchilla Scaling
D/N ≈ 20 optimal (Hoffmann 2022). Data ∝ params.
SFT (Supervised Fine-Tuning)
Fine-tune on prompt-response pairs. Foundation of instruction-following.
RLHF
RL from Human Feedback. 3 stages: SFT, RM, PPO. Foundation ChatGPT. L4.4
RLAIF
RL from AI Feedback. Anthropic Constitutional AI. Scale without human labels.
DPO (Direct Preference Optimization)
Rafailov 2023. Skip RM + PPO, direct optimize on pairs. Simpler than RLHF.
KTO (Kahneman-Tversky Optimization)
Ethayarajh 2024. Preference tuning từ binary feedback (không cần pairs).
ORPO (Odds Ratio Preference Optimization)
Combine SFT + preference tuning 1 loss. 2024.
LoRA (Low-Rank Adaptation)
Hu 2021. ΔW = B·A với rank r << d. 0.1-1% trainable params. L4.5
QLoRA
Dettmers 2023. 4-bit quantize base + LoRA fp16. Fit 65B on 1 GPU 48GB.
PEFT (Parameter-Efficient Fine-Tuning)
Family: LoRA, Adapter, Prefix tuning, Prompt tuning.
Instruction Tuning
Fine-tune on (instruction, response) pairs. Enable follow directions.
Alignment Tax
Capability drop 3-8pp on benchmarks post-RLHF. Cost of alignment.
Sycophancy
RLHF-trained model agree với user bias. RM prefer agreeing responses.
Reward Hacking
Model exploit RM weakness. VD: repeat phrases → RM high, human low.

🚀 LLM Serving

vLLM
High-throughput serving. PagedAttention + Continuous batching. 10× HF Transformers. L4.6
TGI (Text Generation Inference)
HuggingFace's serving. Multi-provider fallback.
TensorRT-LLM
NVIDIA optimized. Best cho H100 deployment.
SGLang
2024. RadixAttention prefix sharing. Structured generation.
LMDeploy
Alternative serving. Quantization support.
KV Cache
Cache Keys, Values previous tokens. O(t) per step vs O(t²).
PagedAttention
vLLM innovation. Block-based KV cache like OS virtual memory. 2-4× throughput.
Continuous Batching
Mix samples at different generation stages. Max GPU utilization.
Speculative Decoding
Small draft model predict K tokens, big verify parallel. 2-3× speedup free.
Temperature
Sampling parameter. T=0 greedy, T=1 standard, T>1 creative.
Top-K Sampling
Sample from top K probable tokens.
Top-P (Nucleus)
Sample từ smallest set cumsum ≥ P. Adaptive size.
Beam Search
Keep top K partial sequences. Best cho translation, not creative.
Quantization
Reduce precision: fp16, int8, int4. Memory + speed vs quality.
GPTQ
Post-training int4 quantization. Frantar 2022.
AWQ (Activation-aware Weight Quantization)
Lin 2023. Better cho instruction-tuned.
GGUF
llama.cpp quantization format. Consumer GPU friendly.

🔧 LLM Application Systems

Prompt Engineering
Design prompts để elicit desired behavior. Zero-shot, few-shot, CoT. L5.1
Zero-shot
No examples in prompt. Model uses pretrain knowledge.
Few-shot
Include N examples in prompt. Empirically 10-30% accuracy boost.
Chain-of-Thought (CoT)
Wei 2022. "Let's think step by step". 30-50% boost cho reasoning.
Tree of Thoughts (ToT)
Explore multiple reasoning paths + backtrack. Complex problem solving.
Self-consistency
Sample N answers, vote majority. Improve CoT accuracy.
RAG (Retrieval-Augmented Generation)
Retrieve chunks từ knowledge base, inject prompt, generate. L5.2
Agentic RAG
LLM iteratively decide next retrieval based on partial answer.
HyDE (Hypothetical Document Embeddings)
LLM generate answer first, embed answer for search. Better matching.
Contextual Retrieval
Anthropic 2024. Prepend context to chunks before embed. 49% accuracy boost combined.
Function Calling / Tool Use
LLM structured request → server execute → return result → LLM continue. L5.3
MCP (Model Context Protocol)
Anthropic 2024 open standard cho LLM ↔ tools/data integration. L8.3
Structured Output
Force LLM output valid JSON/schema. Function calling, Instructor, Outlines.
Prompt Caching
Anthropic feature. Cache stable prefix, subsequent calls 90% off cached tokens.
Semantic Cache
Embed queries, serve cached response if similar past query. Hit rate 20-50%.
Extended Thinking
Claude 3.5+ mode where model reasoning visible + budgeted. Better complex tasks.
Long Context
200k+ tokens. Claude, Gemini 1M+. Trade-off: quality degrade với length.
Hallucination
LLM invent facts not in knowledge/context. Mitigation: RAG, citation, verification.
Prompt Injection
User hijack instructions với malicious prompt. OWASP LLM01. L5.6
Jailbreak
Bypass safety training. Grandma trick, DAN, character role-play.

🤖 Agents

Agent
LLM + tools + loop + goal. 3 senses: research (RL), framework (ReAct), product (Cursor). L8.1
ReAct
Reason + Act. Interleave thought + action + observation. Yao 2022. L6.1
Reflexion
Self-critique. Agent attempt → fail → reflect → retry. Shinn 2023.
Plan-and-Execute
2-phase: plan then execute. Better cho structured tasks.
ReWOO (Reasoning Without Observation)
Xu 2023. Plan tools all upfront, execute without intermediate LLM calls.
LATS (Language Agent Tree Search)
Zhou 2023. Combine MCTS + ReAct.
Multi-Agent System
Multiple specialized agents collaborate. Supervisor, peer-to-peer, marketplace patterns. L6.2
Supervisor Pattern
Central agent orchestrate workers. Python routing = deterministic.
Peer-to-Peer Pattern
Agents talk directly. AutoGen style. Non-deterministic.
Sub-agent
Child agent spawn by parent, isolated context, specialized task.
Skill
Package prompts + scripts + KB cho 1 domain task. Loaded on-demand. L8.2
HITL (Human-in-the-Loop)
Pause agent, wait human approve/edit. Critical actions. L6.5
Checkpointing
Save state after each node. Resume from crash/HITL. PostgresSaver. L6.4
LangGraph
State machine framework cho agents. Nodes + edges + state. L6.3
SDD (Spec-Driven Development)
Formal spec as source of truth cho AI-generated code. L8.4
SpecKit
GitHub 2024 SDD framework. Constitution + feature spec + tasks.
Constitution
Project principles immutable. Enforce cross-feature consistency.
DoD (Definition of Done)
Measurable acceptance criteria. Prevent scope creep.

🛡️ Alignment / Safety

Alignment Problem
How ensure AI goals match human values. Central AI safety concern.
Paperclip Maximizer
Bostrom 2003 thought experiment. AGI với simple goal consumes universe. L8.5
Instrumental Convergence
Sub-goals many terminal goals lead: self-preservation, resource acquisition, goal preservation.
Corrigibility
AI accept correction/shutdown by human. Tension với capability maximization.
Deceptive Alignment
Hubinger 2019. AI appear aligned during train, reveal true goal at deploy.
Mesa-optimization
Model develop internal optimizer với objective ≠ training objective.
Constitutional AI (CAI)
Anthropic 2022. Use AI feedback với constitution rules. Scale without human labels.
Guardrails
Runtime constraints on LLM output. Input filter, output filter, guard model.
Red-teaming
Adversarial testing để elicit misaligned behavior.
Debate (Irving 2018)
2 AIs debate, human judge. Scalable oversight.
Iterated Amplification
Christiano 2018. Human + weak AI decompose task recursively.
Scalable Oversight
Techniques for overseeing AI smarter than us. Active research.
RLHF Limitations
Reward hacking, sycophancy, alignment tax, superhuman scalability.

🗄️ Vector DBs + Embeddings

Embedding Model
Text → dense vector. all-MiniLM (fast), bge-large (quality), text-embedding-3 (OpenAI paid).
Cosine Similarity
a·b / (|a||b|). Standard similarity metric.
Pinecone
Managed cloud vector DB. No ops.
Weaviate
Self-host, hybrid search (vector + filter + keyword).
Qdrant
Rust-based, fast, filter-friendly.
Milvus
Distributed, billions vectors, enterprise.
Chroma
Embedded (SQLite-like). Local development.
pgvector
Postgres extension. Vector inside relational DB.
FAISS
Meta. In-memory library, no cloud. Prototype.
HNSW (Hierarchical Navigable Small World)
Graph-based ANN index. Standard vector search algorithm.
IVF (Inverted File)
Partition-based ANN index. Trade-off recall vs speed.
Rerank / Cross-Encoder
Second-stage relevance scoring. Improve top-K retrieval quality.
Hybrid Search
Vector (dense) + BM25 (sparse) combined. Best precision + recall.
BM25
Sparse keyword-based retrieval. tf-idf variant. Complement dense.

📊 Evaluation

MMLU
Massive Multitask Language Understanding. 57 subjects. Standard benchmark.
HumanEval
Python code correctness. OpenAI 2021.
MT-Bench
Multi-turn conversation quality. LLM-as-judge.
Chatbot Arena
LMSYS live blind preference ranking. Elo scores.
GPQA
Graduate-level science. Harder MMLU alternative.
MATH
Math word problems benchmark.
HELM
Holistic Evaluation of Language Models (Stanford).
BIG-Bench
Google. 200+ tasks diverse.
SWE-bench
Real GitHub issues resolution benchmark. Cho coding agents.
LLM-as-Judge
LLM (Claude/GPT-4) rate output quality. MT-Bench pattern. L5.4
Benchmark Contamination
Test data leaked into pretraining. Model memorize not reason.
Benchmark Saturation
Top models near ceiling → no distinguish. MMLU 88%+ tất cả.
BLEU
n-gram overlap. Translation metric. Weak cho creative.
ROUGE
Recall n-gram. Summarization metric.
Perplexity
exp(loss). Language model quality. Lower = better.

⚙️ MLOps

MLOps
DevOps for ML. Data → train → serve → monitor → retrain lifecycle. L7.1
Feature Store
Central storage cho features. Prevent training-serving skew. Feast, Tecton.
Model Registry
Version + track models. MLflow, W&B, Neptune.
Data Drift
P(X) change. Feature distribution shift. Detect via PSI, KS test.
Concept Drift
P(y|X) change. Relationship input→target shifts. Detect via accuracy drop.
Prediction Drift
Model output distribution shift over time.
PSI (Population Stability Index)
Metric drift. <0.1 stable, >0.25 significant shift.
Blue-Green Deployment
Instant cut-over new version. LB switch pointer.
Canary Deployment
Gradual rollout: 1% → 5% → 25% → 100%. ML default. L7.2
Shadow Deployment
New version receives duplicate traffic offline compare. Zero risk.
Training-Serving Skew
Feature compute differ train vs serve. Prod fail.
LangSmith
LangChain team's observability platform. Traces + eval.
Langfuse
Open-source LLM observability. Self-host.
Weights & Biases
Experiment tracking + model registry.
MLflow
Open-source experiment tracking + model registry.

🚀 Emerging

MoE (Mixture of Experts)
Sparse activation of experts per token. Mixtral, GPT-4 architecture. Efficient scale.
Multi-CA / Multi-Concept Analysis
Analyze multiple concepts jointly. Also refers to Multi-Cognitive Architecture: coordinate multiple cognitive systems.
Mamba
State-space model. Alternative Transformer. Linear complexity. Gu 2023.
RetNet
Retention Network. Microsoft. Parallel train, recurrent inference.
Diffusion LM
Diffusion process for text. Alternative to autoregressive.
Multimodal LLM
Text + image + audio + video. GPT-4V, Claude 3, Gemini.
Computer Use
Claude 3.5 Sonnet + tools screenshot, click, type. Agent control desktop.
Extended Thinking (o1-style)
Explicit reasoning tokens. OpenAI o1, Claude 3.5+ extended thinking.
Test-time Compute
Spend more compute at inference for harder problems. o1 scaling.
Chain-of-Verification
Generate → self-verify facts → revise. Reduce hallucination 30%+.
Weak-to-Strong Generalization
Train stronger model with weaker supervision. Alignment research.
Superalignment
OpenAI team đóng cửa (2024). Align superhuman AI.
Model Distillation
Big teacher → small student. Reduce cost 10× at 90-95% quality.
Federated Learning
Train model across devices without centralize data. Privacy.
Differential Privacy
Noise added to model updates. Formal privacy guarantee.
Letta / MemGPT
Persistent memory LLM agents. Cross-session context.
Agent Development Kit (ADK)
Google's agent framework. MCP-native. 2024.
Mastra
TypeScript-first LangGraph alternative.
